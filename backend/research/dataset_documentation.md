# Dataset documentation

`data/synthetic_requests.csv` is generated by `scripts/generate_synthetic_dataset.py`. It contains 110 templated examples across the 11 starter categories. Every row carries `dataset_type=SYNTHETIC` and a `scenario_id`. It contains no real student submissions, names, identifiers, or college records.

The synthetic corpus exists to exercise the training, inference, and evaluation scripts locally. Similar wording and small sample size make it unsuitable as evidence of institutional performance. Before collecting or importing real data, obtain institutional authorization, remove direct identifiers, document lawful purpose/retention, and preserve a dataset manifest with source, collection date, label process, and consent/approval references. Do not overwrite the provenance column.
